# AAS index PDFs of 2003–2009 (phase 2b′) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Join and create from the seven annual *Index generalis* PDFs of 2003–2009 (AAS 95–101, John Paul II and Benedict XVI), which vatican.va serves under a URL its index page links wrongly, exactly as the 2010–2014 index PDFs were joined in phase 2b-ii-c.

**Architecture:** `tools/fetch-acta.sh` fetches the seven PDFs by the hyphenated URL and extracts them in pypdf's layout mode with the spaces collapsed (the default mode drops the spaces between words in 2003–2006). `tools/src/acta/index.ts` gains three tolerances the fixtures need — the ditto marks the text layer glues, the missing title line of 2006, and a numbered `SYNODUS EPISCOPORUM` heading read as a category when its numeral continues the pope's — and `categories.ts` three headings. `ACTA_SOURCES` lists the seven; the harvest joins and creates; the era report tool gets an era; the pinned tests, README, SCHEMA.md, the fixtures README and the spec move with the numbers.

**Tech Stack:** bash + python3/pypdf 6.14.2 (extraction), TypeScript (tsx, vitest 2), the existing `tools/src/acta/*` modules.

**Spec:** `docs/superpowers/specs/2026-09-13-acta-volumes-design.md` §11 (the addendum of 2026-09-21), read with §4 (the parse rate and its 95 % floor), §6 (the report) and the 2a spec's creation rule and guard.

Below `links_for` in `tools/fetch-acta.sh`, add:

```bash
# The index page links an *Index generalis* PDF for each of 2003-2009 (`AAS 95` ...
# `AAS 101`) under paths the server does not resolve -- `documents/AAS-Index%202002-2009/
# AAS-Index%202005.pdf` (2004-2007, the spaces encoded; 404) and `documents/AAS-Index-2002-
# 2009-AAS-Index-2003.pdf` (2003, the folder folded into the file name; 404) -- while the
# form the 2008 and 2009 links take, `documents/AAS-Index-2002-2009/AAS-Index-{year}.pdf`,
# serves all seven (measured 2026-09-21; acta volumes spec §11.1). The link is read off the
# page as ever and normalised to that form; the README row records both.
index_path_for_0309() { # index_path_for_0309 <year>  -> "<as-linked>|<fetched>"
  local linked
  linked="$(grep -oiE "documents/[^\"']*AAS-Index[^\"']*$1\.pdf" "$INDEX_HTML" | sort -u | head -n1 || true)"
  [ -z "$linked" ] && return 0
  local fetched
  fetched="$(printf '%s' "$linked" | sed -E 's/%20/-/g; s#AAS-Index-2002-2009-AAS-Index-#AAS-Index-2002-2009/AAS-Index-#')"
  printf '%s|%s\n' "$linked" "$fetched"
}

# The text layer of the 2003-2006 index PDFs drops the spaces between words in pypdf's
# default mode (`I—ACTAIOANNISPAULIPP.II`, `honoresdecernuntur`, a page as `4 3 3`), and
# 2005, 2008 and 2009 fuse the volume heading (`An.etvol.C 31Decembris2008`); `space_width`
# changes nothing (measured at 200, 100, 50, 20). The layout mode keeps every space and
# adds the column gaps these PDFs do not have, so each run of two or more spaces is
# collapsed to one and each line trimmed (spec §11.1). One page per form feed, as ever.
extract_whole_collapsed() { # extract_whole_collapsed <pdf> <out>
  python3 - "$1" "$2" <<'EOF'
import re, sys
from pypdf import PdfReader
pdf, out = sys.argv[1], sys.argv[2]
pages = [(p.extract_text(extraction_mode='layout') or '') for p in PdfReader(pdf).pages]
pages = ['\n'.join(re.sub(r' {2,}', ' ', line).strip() for line in page.split('\n')) for page in pages]
with open(out, 'w', encoding='utf-8') as f:
    f.write('\f'.join(pages))
    f.write('\n')
print(f'    {len(pages)} pages -> {out} (layout mode, spaces collapsed)')
EOF
}
```

const untangleIndexLine = (line: string): string => {
  let l = line.replace(SPACED_PAGE_END_RE, (m, digits: string) => m.replace(digits, digits.replace(/ /g, '')));
  l = l.replace(GLUED_DITTO_DAY_RE, '$1» » ');
  l = l.replace(DOUBLED_DITTO_RE, '$1» »');
  l = l.replace(DOUBLED_DITTO_RE, '$1» »');

  l = l.replace(GLUED_DAY_TEXT_RE, '$1 ');
  return l;
};
