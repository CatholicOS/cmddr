# The *Acta Sanctae Sedis* under Pius X (phase 2c-ii-b) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Join the five unjoined volumes of Pius X's pontificate — ASS 36–40 — to the shelves, so the densest and best-scanning end of the series carries its references. ASS 41 is already joined (phase 2c-i); this era completes the pontificate.

**Architecture:** 2c-i's shape with the tooling 2c-ii-a built — `ACTA_SOURCES` rows, the scan to fixtures, a curation round that counts before it writes a rule, the join, the harvest, the pins, an era report. The scanner and the summa parser are finished work: this phase adds *sources and curated rows*, not rules, and any rule it does reach for is measured over all 41 volumes before it is accepted.

**Tech Stack:** TypeScript (ESM, `tsx`), vitest, `gh`.

**Spec:** `docs/superpowers/specs/2026-09-21-ass-volumes-design.md` — §2 (fetch and fixtures), §5 (the join), §6 (curation), §7 (report, tests, documentation), and §10 decision 3, which defines this era.

## Three things this era should expect

1. **Pius X has no briefs shelf and no bulls shelf** (`pontiffs.ts`: his shelves are `apost_constitutions`, `apost_exhortations`, `apost_letters`, `encyclicals`, `letters`, `motu_proprio`). ASS 39 and 41 end their papal part at `EX SECRETARIA BREVIUM`, and 2c-i already found every one of ASS 41's ring brevia held for exactly this reason. **Brevia read in these volumes will be held, not matched**, and that is the registry's gap rather than the scan's — the same finding 6 made for the sample. Expect it, count it, and do not curate around it.
2. **ASS 38 carries a bound-in supplement.** Its summa sits at pp. 417–423 while the volume runs to 702, and `Supplementum ad "Acta S. Sedis„` occupies 433–702 — 270 pages — with a separately paginated French supplement inside it numbered from 1. The survey already names this as a floor. The scan must not read the supplement's pages as the volume's own, and the 13 acts it reads are the lowest count of the five: check whether the supplement hides more.
3. **ASS 36 is a two-pope volume.** Leo XIII died 20 July 1903 and Pius X was elected 4 August; the volume prints both. The join matches per issuer, so nothing special is needed — but the era report must not describe it as Pius X's alone, and its Leo XIII acts belong to 2c-ii-c's count, not this one.

## Global Constraints

- **Nothing is guessed.** A reading is curated only where the volume's own line is quoted (`ASS_READINGS`, `tools/src/acta/curation.ts`); a shape that recurs across volumes is a rule, and a rule is measured over all 41 volumes with `tools/survey-ass.ts` before it is accepted (spec §3, §6).
- **`series: 'ASS'` entries are joined, never created** (spec decision 1). The creator holds them `series-not-created`.
- The store is the source: `~/development/sources/ASS/{txt,pdf}/`, all 41 volumes present. PDFs and text are never checked in.
- `npm run check` (vitest + tsc + validate) passes at every commit, and `npm run harvest && npm run render` is run before any commit that moves data.
- Every count stated in prose must be computed by the generator or asserted by a pin. Prose that names acts must read them from the tables (the lesson of PR #51, where a hand-written list drifted from the rule column).
- Work in a worktree under `.worktrees/` created from local `main`, branch `feat/ass-pius-x`; one PR at the end, and a comment on [#25](https://github.com/CatholicOS/cmddr/issues/25).

- [ ] `npm run check` — it should fail only where a test asserts the source count or the absence of these fixtures. Record which.

## Task 2 — The scan

- [ ] `npx tsx tools/scan-ass.ts 36-40`, which writes both fixtures per volume and prints the counts for the README row.
- [ ] Compare each volume's printed counts against the survey table above. **Any divergence is a finding, not a nuisance**: the survey and the scan run the same scanner, so a difference means the fixture path sees something the store pass did not.
- [ ] Add the five rows to `tools/fixtures/acta/README.md`.
- [ ] Inspect ASS 38 specifically: confirm the summa located is the volume's own (pp. 417–423) and that no entry's page falls in the supplement's 433–702.

## Task 3 — The curation round

- [ ] For each volume, list what the scan could not read: defects, summa rows unclaimed, and acts the summa omits. Group them by reason before writing anything.
- [ ] Curate only what recurs as a one-off: an `ASS_READINGS` row per act, quoting the volume's own heading and dateline, as 2c-i's 24 readings do. **Count first**: if a shape occurs in three or more volumes it is a rule for a later phase, not a row here, and it goes in the report instead.
- [ ] Do not curate the brevia held for want of a Pius X briefs shelf (see expectation 1). They are counted and reported.

## Task 4 — The join

- [ ] `npm run harvest && npm run render`, and record the summary line's movement: matched, ambiguous, unmatched, claimed twice.
- [ ] Any ambiguity is read and settled by a curated row quoting its evidence, or reported as an editorial question for the owner — never guessed. 2c-i had none; this era is five times the size.
- [ ] Any page two matched acts share needs an `ACTA_SHARED_PAGES` row, or invariant 25 withholds **both** references (the lesson of PR #51's `ASS:33:3`).

## Task 5 — The pins

- [ ] Pin matched per volume, the held count and its reasons, and the corpus totals, in `tools/test/harvest-data.test.ts`, in the shape 2c-i's pins already have.
- [ ] Every number in the pins' prose must match the report's computed value. Cross-check them against the generated report, not against the scan log.

## Task 6 — The era report

- [ ] Write `docs/superpowers/reports/2026-09-25-ass-volumes-pius-x.md` from a generator, following `tools/ass-volumes-report.ts`: what each volume scanned, what the summa said, what matched and by which rule, what did not, and the reverse gap of the volume years.
- [ ] Every figure the prose states must be computed. Where the prose names acts, it reads them from the tables.
- [ ] The findings answer: how much of Pius X's shelf now carries a reference, what the brevia cost, what ASS 38's supplement hid, and what 2c-ii-c should expect from Leo XIII's twenty-one remaining volumes.
